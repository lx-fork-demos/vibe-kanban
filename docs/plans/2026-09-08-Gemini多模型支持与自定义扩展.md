# Gemini 执行器多模型支持与自定义配置扩展方案

## 1. 需求背景与目标
在 Vibe Kanban 客户端中配置 Gemini API Key 后，模型下拉菜单仅硬编码展示 3 个预览模型（`Gemini 3 Flash`、`Gemini 3 Pro`、`Gemini 3.1 Pro Preview`），无法使用 Google 发布的如 Gemini 2.5 Pro、Gemini 2.5 Flash、Gemini 2.0 Flash 等主流与最新模型。
本方案旨在：
1. 扩充内置官方支持的主流模型列表。
2. 支持从本地配置文件（`~/.config/vibe-kanban/gemini_models.json`）动态载入自定义模型，提供未来可持续扩展能力。

## 2. 行为契约 (BDD)
- **Given（前提）**：用户在 Vibe Kanban 中选中 Gemini 执行器。
- **When（触发）**：执行器调用 `discover_options` 发现可用配置时。
- **Then（结果）**：
  - 默认返回包含 Gemini 2.5 Pro、2.5 Flash、2.0 Flash、1.5 Pro、3.1 Pro Preview 等完整的模型列表；
  - 若用户在 `~/.config/vibe-kanban/gemini_models.json` 中配置了自定义模型，执行器将读取并合并去重，自定义模型置顶或优先展示；
  - 用户选中的任意有效模型 ID，均能通过 `--model <id>` 正常透传给底层的执行子进程。

## 3. 实施改动范围
- 目标文件：`crates/executors/src/executors/gemini.rs`
- 新增逻辑：
  - `DEFAULT_GEMINI_MODELS` 预设列表。
  - `load_custom_gemini_models()` 辅助函数，安全解析外部 JSON。
  - 单元测试函数 `test_gemini_model_discovery()` 验证模型列表解析与构建。
